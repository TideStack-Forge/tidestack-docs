运维管理

本栏目面向负责潮汐栈部署、发布和持续运行的实施与运维人员。首次部署从环境准备开始，日常维护和故障处理可直接进入对应任务。

开发平台部署​

任务文档完成结果
选择平台、运行后端和访问入口部署架构对照 Docker、APISIX、Kubernetes 各模式的架构图确定部署方案
在同一主机安装平台和 Docker 运行实例Docker Compose 部署完成环境准备、安装、首次登录和临时端口访问验证
为 Docker 测试应用提供稳定域名Docker + APISIX 部署配置共享网络、网关、DNS 与路由生命周期
将运行实例放到另一台 Docker 主机远程 Docker Engine 部署对齐 API 接入、共享目录和跨主机依赖
使用集群承载运行实例或自行编排平台Kubernetes 部署配置客户端、共享 PVC、NodePort / Ingress，明确平台编排要求

“部署方式”下各篇按环境要求、配置、初始化和验证组织。个人体验可以直接使用 快速上手；团队共享环境先选择部署方式，完成平台和实例验收，再建立监控、备份和恢复流程。

配置参考​

配置对象文档查询内容
统一运行基座 ouroboros-mothership统一运行基座配置项配置加载顺序、JVM、依赖、认证、文件和实时通信参数
开发平台 ouroboros-develop开发平台配置项平台覆盖值、工作区、Docker / Kubernetes、调试、模板和配置中心默认值

开发平台继承基座的通用配置，两篇参考分别标注镜像内置值和代码默认值。安装步骤见上一组，查具体参数时从这里进入。

发布与变更​

变更对象文档需要分别记录的版本
应用模型、页面、流程、权限和扩展包业务应用发布与回退应用快照、基座镜像、业务数据库
开发平台镜像和运行配置平台升级与回滚平台镜像、配置、平台数据库

发布应用版本会创建元数据快照；运行实例使用哪个镜像、工作区和数据库，需要单独确认。平台升级也需要单独验证应用运行结果。

日常维护​

维护对象文档主要检查
上传文件和文档库文件与文档维护持久化路径、容量、权限和文件一致性
计划任务、消息消费和实时推送任务、消息与实时链路维护从触发到业务结果的完整链路
用户操作及业务结果业务日志与审计回溯模板匹配、业务键、脱敏和查询

监控与恢复​

当前需要文档完成结果
建立巡检和告警监控与告警能识别入口、依赖、运行实例和容量异常
执行备份、恢复或演练备份与恢复数据、配置、工作区和文件可以配套恢复
处理访问、登录、启动或积压故障故障排查根据证据定位故障层，恢复后验证业务结果

本栏目中的 Compose 命令以配套示例的服务名为准。使用外部依赖或 Kubernetes 运行后端时，在对应组件上执行检查；业务应用的问题应查看目标实例的日志和数据源。
