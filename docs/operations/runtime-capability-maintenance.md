# 运行能力维护要点

启用文件、文档、调度、消息、WebSocket 或业务日志后，把相应依赖加入持久化、备份、监控和变更验证。

## 维护清单

| 能力 | 必须持久化或配置 | 日常检查 | 恢复后验证 |
| --- | --- | --- | --- |
| 文件上传 | 上传目录、访问地址、临时文件清理 | 容量、挂载、清理失败 | 上传、下载、删除一份测试文件 |
| 文档管理 | 数据库元数据和文档库存储根目录 | 容量、目录权限、所有者 | 目录、权限、下载和重命名 |
| 计划任务 | 任务定义、Quartz 数据和时区 | 关键任务最后结果、执行错误 | 巡检任务触发并产生业务结果 |
| 消息队列 | RabbitMQ 数据、绑定和凭据 | 节点状态、消费者、积压和未确认消息 | 唯一消息完成生产与消费 |
| WebSocket | 代理 Upgrade、鉴权和连接配置 | 连接失败、鉴权失败、断线重连 | 真实页面收到状态变化 |
| 业务日志 | 日志模板、日志数据和保留策略 | 写入连续性、容量、脱敏 | 关键操作产生可查询日志 |

## 文件与文档存储

1. 把上传目录和文档库存储目录挂载到持久化磁盘。
2. 将 `ouroboros.document-management.storage.filesystem.base-path` 指向文档库存储根目录。
3. 同一时间点备份数据库元数据和文件内容。
4. 设置容量阈值、临时文件清理和备份保留周期。
5. 在恢复环境中上传、下载和删除附件；再验证文档库目录、所有者和 ACL。

只恢复数据库或只恢复文件都不能得到完整的附件和文档库。

## 任务、消息与实时通信

使用 [任务、消息与实时链路维护](./task-message-and-realtime-link-maintenance) 执行专项巡检。以下变更后必须重复三条端到端验证：

- 平台或业务应用升级。
- 数据库、RabbitMQ、代理、域名或端口变化。
- 认证、时区、运行节点或部署架构变化。

## 业务日志

对权限、配置、审批和关键业务单据配置业务日志模板。模板至少给出稳定业务键、可读摘要、敏感字段和是否保存响应体；操作步骤见 [业务日志与审计回溯](./business-logs-and-audit-traceability)。

## 备份范围

完整备份至少包含：

- 平台数据库和业务数据库。
- 上传文件和文档库存储目录。
- `.env`、Compose 文件、`application.yml` 和受控凭据引用。
- 开发工作区、应用版本 ZIP 和镜像清单。
- RabbitMQ 中需要持久化的定义和数据。
- 业务日志数据及其模板。

备份完成不等于可恢复。恢复演练必须核对数据库、文件、权限、任务、消息和应用核心操作。命令见 [备份、监控与排障](./backup-monitoring-and-troubleshooting)。
