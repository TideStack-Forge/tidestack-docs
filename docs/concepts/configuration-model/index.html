配置模型

配置模型声明应用运行时可读取和管理的参数：键名是什么、值按什么类型解释、缺省时采用什么值，以及允许怎样修改。配置定义随应用交付，运行时保存的配置值可以覆盖定义中的默认值。

定义、默认值与当前值​

一个配置项有三个需要分清的部分：定义描述规则，默认值写在定义中，当前值由运行时配置服务读取。已保存覆盖值时采用覆盖值，没有保存时回到默认值，再按 valueType 转为应用使用的类型。

例如，定义一个默认关闭、可由管理员启用的功能开关：

{
  "key": "feature.previewEnabled",
  "label": "启用预览功能",
  "description": "控制应用是否提供预览入口",
  "valueType": "boolean",
  "defaultValue": "false",
  "modifiable": true,
  "nullable": false,
  "groupPath": "features",
  "scope": "backend",
  "editorSchema": { "type": "switch" }
}

保存运行时值 true 后，更改定义里的默认值不会覆盖这个已保存值。配置键是读取和保存的依据，重命名配置键时需要一并处理消费者与原有覆盖值。

值类型与编辑方式​

int、long、float、double、boolean、string 表达基础值；object、map 表达对象，list、array 表达列表。默认值在元数据对象中以字符串保存，JSON 加载时也接受数值或对象并转为字符串表示，运行时再根据类型转换。

editorSchema 决定管理页面采用什么输入控件。编辑器、值类型和业务消费者的预期应一致，例如布尔开关使用布尔类型；复杂对象使用相应的结构化编辑表单。页面校验有助于输入，后端仍会检查修改许可、可空性和值的有效性。

配置还可以声明 managementEntry，把维护工作交给专用管理页面。它必须是以 / 开头、且不以 // 开头的站内路径；声明后，系统配置工作台不再为该项生成通用编辑表单。适合需要专门操作流程的配置。

前端范围与后端范围​

scope 表示配置的使用端，默认是 backend。frontend 范围的值会提供给前端使用，不应包含凭据、密钥或其他敏感信息。它不是租户或部门的数据隔离开关，也不表示配置已经授权给某个角色。

需要动态调整的应用参数使用统一配置；数据库连接、启动端口等固定启动参数按部署方式使用 Spring 配置。业务记录仍应放在业务模型或数据模型中。

核心属性​

配置项​

属性作用说明
key配置键运行时读取配置的稳定标识。
label配置标题管理页面显示的名称。
description配置说明解释配置的用途和影响。
valueType值类型支持数值、布尔、字符串、对象和列表等类型。
defaultValue默认值未设置覆盖值时采用；元数据以字符串保存，并按值类型转换。
modifiable允许修改控制配置值是否可通过管理能力修改。
nullable允许为空决定空值是否属于合法状态。
groupPath所属分组引用配置分组的路径。
order展示顺序控制配置项在分组内的排序。
scope使用端frontend 表示前端配置，backend 表示后端配置。
obsolete废弃标记标明配置项是否已废弃。
obsoleteCause废弃原因说明废弃缘由及替代方式。
editorSchema编辑器定义描述配置值的输入界面和校验方式。
managementEntry专用管理入口站内绝对路径；由专用页面接管维护。
managementAccessPolicyRequired管理保护标记扩展属性；要求专用管理访问策略，受保护定义不能同键覆盖。
extraProps扩展属性按属性名平铺在 JSON 中，由相应能力消费。

配置分组​

属性作用说明
path分组路径标识配置分组及其层级位置。
title分组标题配置管理界面中显示的名称。
icon分组图标用于识别分组。
order展示顺序控制同级分组排序。
description分组说明解释该组配置的用途。
extraProps分组扩展属性按属性名平铺，由分组使用方解释。

分组和运行时修改​

配置分组通过 path 标识，配置项以 groupPath 引用分组。分组用于整理管理界面，不改变配置键，也不为组内配置自动建立值的继承关系。

运行时修改会记录更新信息和修订号。使用带修订号的保存接口时，如果配置已被其他操作修改，保存会报告版本冲突；应重新读取并核对当前值后再提交，避免覆盖别人的变更。部分受保护配置还要求专用的管理访问策略，不能仅通过修改元数据解除限制。

常见问题​

改了默认值，为什么运行时还是旧值？​

检查是否已经保存过运行时覆盖值。读取服务优先采用已保存值；仅修改默认值不会替换覆盖值。

为什么配置在列表里却没有普通编辑表单？​

检查是否声明了 managementEntry。这类配置由专用页面接管；同时检查该项是否可修改、是否受管理策略保护。

可以用前端配置保存访问外部系统的密钥吗？​

不可以。前端配置用于浏览器可读取的参数，外部服务凭据应留在后端的凭据或受保护配置机制中。
