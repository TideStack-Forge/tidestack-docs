# 应用模型

应用模型定义一个潮汐栈应用的边界和基础身份。它承载应用级配置，不承载具体业务对象、页面流程或权限规则。

## 作用

- 为模块、业务模型、页面和运行配置提供所属应用边界。
- 维护应用对外显示的名称、图标、Logo、首页和默认主题。
- 为应用开发、版本发布和运行实例提供稳定的识别信息。

## 核心属性

| 属性 | 作用 | 说明 |
| --- | --- | --- |
| `name` | 应用标识 | 应用内部稳定名称，参与文件和运行时识别。 |
| `title` | 应用标题 | 面向用户显示的应用名称。 |
| `description` | 应用说明 | 描述应用用途和边界。 |
| `icon` | 应用图标 | 用于导航、应用列表或工作台展示。 |
| `logo` | 应用 Logo | 用于应用品牌区域或登录入口。 |
| `homePage` | 默认首页 | 应用进入后的默认页面入口，通常关联 UI 模型。 |
| `defaultTheme` | 默认主题 | 应用级主题和视觉配置的默认值。 |
| `custom` | 扩展属性 | 只放经过约定的应用级扩展，不替代专用模型属性。 |

## 与其他模型的关系

- [模块模型](../module-model/) 是应用内部的功能组织结构。
- [业务模型](../business-model/)、[UI 模型](../ui-model/) 和 [配置模型](../configuration-model/) 都在应用边界内生效。
- `homePage` 指向页面入口，页面的具体实现由 [UI Schema](../ui-schema/) 或微前端资源承担。
- 应用版本会聚合应用内的模型、菜单、权限、流程和配置，再交给运行实例消费。

## 不负责什么

应用模型不应直接描述数据库字段、HTTP 参数、流程节点或角色授权。需要表达这些内容时，分别进入对应的业务、数据、WebAPI、流程和权限模型。
