# 数据字典模型

数据字典模型定义一组受控的选项、状态或分类值。它为字段、页面、逻辑流和查询条件提供稳定值域，不承担业务对象本身的持久化语义。

## 作用

- 统一维护状态、分类、地区、单位等可复用选项。
- 支持平面字典和树形字典，减少页面和模型中的重复枚举配置。
- 为字段类型和 UI 控件提供可选择的数据来源。
- 在状态型场景中承载值转换和状态流转约定。

## 核心属性

| 属性 | 作用 | 说明 |
| --- | --- | --- |
| `name` | 字典标识 | 运行时查询和模型引用使用的稳定名称。 |
| `title` | 字典标题 | 面向开发者和用户显示的名称。 |
| `type` | 值类型 | 约束字典项值的基本类型和转换方式。 |
| `group` | 字典分组 | 按业务域或管理边界组织字典。 |
| `editable` | 是否可编辑 | 控制运行态或管理态是否允许修改字典项。 |
| `treeMode` | 是否树形 | 开启后字典项可表达父子层级。 |
| `items` | 字典项集合 | 包含值、标题、排序、父项和扩展属性等信息。 |

## 与其他模型的关系

- [字段定义](../field-define/) 可以把数据字典作为字段的可选值来源。
- [业务模型](../business-model/) 和 [数据模型](../data-model/) 保存引用字典值的业务字段。
- [UI Schema](../ui-schema/) 使用字典渲染选择器、级联选择和状态显示。
- [逻辑流模型](../logicflow-model/) 可以按字典值执行条件分支或状态转换。

## 设计边界

字典适合稳定、可复用、值域有限的数据。客户、订单、设备等需要独立字段、关系、生命周期和权限的数据对象，应使用业务模型或数据模型，不应把字典扩展成业务主数据表。
