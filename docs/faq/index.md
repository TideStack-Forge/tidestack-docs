# 常见问题

按症状查找原因、检查项和修复入口：

| 分类 | 问题 |
| --- | --- |
| [后端](./backend/) | 扩展未加载、字段运行时不可用、模型查找失败、表达式空值和权限问题 |
| [前端](./frontend/) | 页面发布未生效、SDK 调用时机、请求结果、选择器值和重复订阅 |
| [运维](./operations/) | 平台与实例启动失败、任务和消息异常、发布回退及备份 |

排查时先记录目标环境和版本、发生时间、操作步骤、完整错误消息，再按对应页面检查。HTTP 问题同时保留状态码和响应体；运行问题保留相关日志，凭据与个人信息先脱敏。

方法和参数见 [API 参考](../api/)，需要完整环境排查流程时使用 [故障排查](../operations/troubleshooting)。
