# 模块专题

按当前任务进入对应模块：

| 任务 | 专题 | 完整交付指南 |
| --- | --- | --- |
| 设计、发起、处理或统计审批 | [审批流](./approval-workflow/) | [流程、规则与自动化](../../low-code/workflow-rules-and-automation) |
| 维护公司、部门、岗位和员工 | [组织架构管理](./organization/) | [组织、权限、配置与通知](../../low-code/organization-permissions-configuration-and-notification) |
| 配置用户、角色和访问范围 | [用户角色权限](./rbac/) | [组织、权限、配置与通知](../../low-code/organization-permissions-configuration-and-notification) |
| 查看站内信 | [消息通知](./notification/) | [组织、权限、配置与通知](../../low-code/organization-permissions-configuration-and-notification) |
| 创建数据集、图表和仪表板 | [统计分析](./statistics-analysis/) | [低代码开发](../../low-code/) |

需要按完整业务交付顺序操作时，从 [从需求到交付](../../low-code/from-requirement-to-delivery) 开始。
