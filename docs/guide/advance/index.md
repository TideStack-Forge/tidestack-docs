# 高级开发参考

需求已经确定需要代码扩展时，按扩展对象查阅本目录：

| 扩展对象 | 入口 | 交付结果 |
| --- | --- | --- |
| 页面、登录页或完整交互 | [扩展前端](./extend-frontend/) | 微前端包 |
| 顶栏、侧栏等平台框架区域 | [扩展前端](./extend-frontend/) | 布局组件 |
| 低代码页面组件 | [扩展前端](./extend-frontend/) | 组件库 |
| 字段、表达式、脚本或逻辑流节点 | [扩展后端](./extend-backend/) | 后端扩展 JAR |
| Claims、主体或数据访问控制 | [权限与访问控制](./authority-and-access-control) | 安全扩展实现 |
| AMIS 页面实现细节 | [AMIS 开发参考](./amis-reference/) | 页面 Schema 或组件实现 |

尚未确定是否需要写代码时，先用 [何时用低代码，何时写代码](../../fusion-development/when-to-use-code) 判断；确认扩展类型后，用 [平台扩展点总表](../../fusion-development/extension-points) 选择具体接口。
