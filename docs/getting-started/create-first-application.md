# 创建第一个应用

使用本页创建一个名为“客户管理”的空应用。完成后，你可以进入应用开发工作区并创建业务模型。

## 开始前

- 开发平台已经启动。
- 你可以使用管理员或具有应用创建权限的账号登录。
- 本示例使用应用名 `customerManagement`。应用名创建后会被模型、接口和页面引用，不要使用中文或空格。

## 创建应用

1. 登录开发平台，打开 **打开应用**。
2. 点击页面右上角的 **创建应用**。

   ![打开应用页面](../guide/tutorial/apps/.assets/create-app-1.png)

3. 按下表填写表单。

   | 字段 | 填写值 |
   | --- | --- |
   | 应用名 | `customerManagement` |
   | 应用标题 | `客户管理` |
   | 图标 | 留空 |
   | 描述 | `客户资料维护示例` |

4. 点击 **确认**。

   ![创建应用表单](../guide/tutorial/apps/.assets/create-app-2.png)

5. 在应用列表中找到 **客户管理**，点击应用卡片进入开发工作区。

## 完成标志

应用创建成功后，你会看到应用开发工作区，并能从左侧菜单打开 **业务模型**、**版本管理** 和 **应用配置**。

## 常见问题

### 提示应用名已存在

应用名必须唯一。把应用名改为未使用的英文标识，例如 `customerManagementDemo`，应用标题仍可使用“客户管理”。

### 创建按钮不可见

当前账号没有应用创建权限。使用管理员账号登录，或让管理员为当前角色分配应用管理权限。

### 创建后无法进入应用

刷新 **打开应用** 页面；应用仍不存在时，查看平台日志中的应用创建错误。应用存在但打不开时，检查浏览器控制台和平台接口响应。

继续使用刚创建的应用完成 [第一个业务功能](./first-business-feature)。完整字段说明见 [开发应用](../guide/tutorial/apps/)。
