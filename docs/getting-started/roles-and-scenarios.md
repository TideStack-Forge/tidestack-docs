# 角色与典型场景

按当前任务选择路径，不需要从头通读全部手册。

| 角色 | 负责的结果 | 首选入口 |
| --- | --- | --- |
| 业务开发人员 | 应用、模型、标准页面、流程、权限和通知 | [低代码开发](../low-code/) |
| 专业开发人员 | 微前端、组件、后端扩展和深度集成 | [融合开发](../fusion-development/) |
| 实施人员 | 环境准备、初始化、账号和交付验收 | [安装与初始化](../operations/installation-and-initialization) |
| 运维人员 | 发布、升级、备份、监控和故障恢复 | [运维管理](../operations/) |
| 平台管理员 | 组织、角色、运行实例和平台级能力治理 | [开发菜单速查](../low-code/development-platform-menu-guide) |

## 常见分工

- 业务开发人员定义稳定的业务对象、标准页面和流程。
- 专业开发人员只接管超出内建能力的页面、节点、协议或算法。
- 实施与运维人员负责环境、凭据、发布记录、备份和恢复。
- 平台管理员负责公共组织、权限和可复用能力，不介入单个业务模型的日常配置。

同一个人承担多个角色时，仍应分别执行开发验收、权限验收和运维验收，不能用管理员账号代替普通用户验收。
