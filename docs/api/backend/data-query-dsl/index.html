数据查询 DSL

使用 Map/List 描述字段、条件、排序、分页和关联。业务代码通常把语句传给 DataModel.query(statement)；Java 也可以使用 model.query() 构建语句并执行。

以下示例假设已定义 crm.Order 模型，包含 id、status、amount、createdAt 等字段。关联示例还要求模型中定义了对应关系。模型查询使用模型字段名，不使用数据库列名。

查询一页数据​

Groovy 脚本可直接执行：

def orders = DataModelCenter.get('crm.Order')
if (orders == null) {
    Exceptions.business('订单模型不可用')
}
def rows = orders.query([
    select: ['id', 'amount'],
    where: [status: 'OPEN', amount: [greaterThanOrEqual: 100]],
    order: [createdAt: 'DESC', id: 'ASC'],
    skip: 0,
    limit: 20
]).get()
rows

.get() 取出 Try 中的结果，查询失败时抛出异常。需要总数时，单独调用 orders.count(where).get()，不要把当前页长度当作总数。

查询语句字段​

字段常用值用途
select['id', 'amount']返回字段或表达式
omit['internalNote']从模型查询中排除字段
where[status: 'OPEN']过滤条件
order[createdAt: 'DESC', id: 'ASC']排序
skip / offset0跳过条数，两者等价
limit20返回条数
populate['customer']填充已定义的关联字段，限模型查询
distincttrue去重
from'crm.Order' 或 [o: 'crm.Order']数据来源；在模型上查询时可省略
join / leftJoin 等关联定义连接数据源
group / having分组字段 / 条件聚合查询
union / unionAll查询列表合并结果，后者保留重复行

关键字不区分大小写。复杂连接、聚合和集合查询的执行能力取决于目标数据适配器，应在应用使用的数据源上验证。

SELECT：字段和别名​

def statement = [
    select: ['id', [orderAmount: 'amount']],
    where: [status: 'OPEN']
]

别名写作 [返回名称: '模型字段']。省略 select 时使用模型默认投影；只需要少量字段时明确列出字段。

聚合字段用列表表达式：

def statement = [
    select: ['status', [count: ['count', ['id']]]],
    group: ['status'],
    having: ['>', ['count', ['id']], 10]
]

WHERE：过滤条件​

等值、范围和集合​

同一 Map 中多个字段默认按 AND 组合。

def where = [
    status: 'OPEN',
    amount: [greaterThanOrEqual: 100, lessThan: 1000],
    departmentId: ['sales', 'support']
]

字段对应列表时表示 IN。用 notIn 表示排除集合：

def where = [status: [notIn: ['CLOSED', 'CANCELLED']]]
常用操作符常见等价写法含义
equal=, ==, eq等于
notEqual!=, <>, ne不等于
greaterThan>, gt大于
greaterThanOrEqual>=, gte大于等于
lessThan<, lt小于
lessThanOrEqual<=, lte小于等于
between—闭区间
in / notIn—属于 / 不属于集合
like / notLike—使用匹配模式
startsWith / endsWith—前缀 / 后缀匹配
isNull / isNotNull—空值 / 非空值

操作符不区分大小写。like 的 % 等模式字符按目标数据源的匹配规则解释。

def range = [amount: [between: [100, 1000]]]
def prefix = [code: [startsWith: 'ORD-']]

AND、OR 和 NOT​

def where = [
    status: 'OPEN',
    or: [
        [departmentId: 'sales'],
        [amount: [greaterThan: 10000]]
    ]
]

结果为 status = OPEN AND (departmentId = sales OR amount > 10000)。显式组合可使用 and、or、not，也支持 xor、xnor。

def where = [not: [status: 'CLOSED', departmentId: 'sales']]

上例对整个内部条件取反，即 NOT (status = CLOSED AND departmentId = sales)。

字段比较和空值：S 表达式​

S 表达式写作 ['操作符', 参数1, 参数2, ...]。字段用列表表示，字符串常量直接写字符串：

// 比较两个字段，而不是把 updatedAt 当成字符串常量。
def changed = ['!=', ['createdAt'], ['updatedAt']]
def missing = ['isNull', ['approvedAt']]
def expensive = ['>', ['amount'], 1000]

Map 条件与 S 表达式可以组合：

def where = ['and', [status: 'OPEN'], ['>', ['amount'], 1000]]

[createdAt: 'updatedAt'] 表示字段等于字符串常量，不表示两个字段相等。

排序与分页​

def statement = [
    order: [[createdAt: 'DESC'], [id: 'ASC']],
    skip: 20,
    limit: 20
]

也支持 'createdAt DESC'、['createdAt DESC', 'id ASC'] 等排序形式。分页时应包含稳定排序，必要时增加主键作为第二排序字段。

POPULATE：关联数据​

def statement = [
    select: ['id', 'customer'],
    populate: [customer: [select: ['id', 'name']]],
    limit: 20
]

customer 必须是模型中已经定义的关联字段。只需默认关联投影时可写 populate: ['customer']。此语法用于模型查询，不能把任意数据库列当作关联字段。

JOIN、子查询和 UNION​

以下示例要求目标适配器支持对应查询，并已存在 crm.Customer 数据来源：

def statement = [
    from: [o: 'crm.Order'],
    select: ['o.id', [customerName: 'c.name']],
    leftJoin: [[c: 'crm.Customer', on: ['o.customerId': 'c.id']]],
    where: ['=', ['o.status'], 'OPEN'],
    limit: 20
]

来源也可以是子查询，例如 from: [o: [select: ['id'], from: 'crm.Order']]。合并查询时，两边投影应兼容：

def statement = [
    select: ['id'], from: 'crm.Order', where: [status: 'OPEN'],
    union: [[select: ['id'], from: 'crm.Order', where: [status: 'PENDING']]]
]

Java 查询构建器​

import static com.ouroboros.data.dsl.query.Query.field;
import java.util.Map;
import com.ouroboros.data.model.DataModelCenter;

var orders = DataModelCenter.getDataModel("crm.Order")
    .orElseThrow(() -> new IllegalStateException("订单模型不可用"));
var rows = orders.query()
    .select(field("id"), field("amount"))
    .where(field("status").eq("OPEN"))
    .clause("order", Map.of("id", "ASC"))
    .clause("limit", 20)
    .execute().get();

build() 只返回 Map 语句，execute() 执行并返回 Try<RecordList>。where 设置条件，andWhere/orWhere 追加组合条件；clause(name, value) 设置排序、分页等其他语句字段。强类型模型同样提供 query() 入口。

增删改使用模型接口​

常规业务写入直接传数据和条件，不需要自行拼接 insert/update/delete 语句：

orders.insert([id: 'order-001', status: 'OPEN', amount: 100]).get()
orders.update('order-001', [status: 'CLOSED']).get()
orders.delete('order-001').get()

这些调用会执行模型配置的校验和插件。构建查询时只接收业务允许的字段和操作符，数据权限按应用接口契约处理；不要将外部输入直接拼为 SQL 字符串。
