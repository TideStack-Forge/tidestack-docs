# 集成与定时自动化

本页用于配置数据库连接、复用已发现的 Web API、调用外部 HTTP 服务，以及用计划任务或消息队列触发逻辑流。

## 选择能力

| 任务 | 使用能力 |
| --- | --- |
| 让应用引用平台统一维护的数据库连接 | 平台数据源 + 应用数据源 |
| 修改应用中已发现 Web API 的处理方式 | 后端接口 |
| 调用外部 HTTP 服务 | 外部身份认证 + 外部接口 |
| 按 Cron 周期执行逻辑流 | 计划任务 |
| 异步生产或消费事件 | 消息队列 |

需要同时完成多步数据处理、判断和调用时，先创建 [逻辑流](../guide/tutorial/logicflow/)，再把它绑定到接口、任务或消息消费者。

## 绑定数据源

### 前置条件

- 管理员已取得数据库 JDBC 地址和专用账号。
- 网络和防火墙允许平台访问数据库。
- 已确认目标驱动类型：MySQL、Oracle、PostgreSQL、KingbaseES 或 SQL Server。

### 操作步骤

1. 管理员在平台数据源管理中创建数据源，填写名称、标题、环境、JDBC 类型、驱动、URL、用户名和密码。
2. 测试或保存连接，确认没有驱动、认证或网络错误。
3. 应用开发者进入应用的 **数据源** 页面，创建应用数据源名称。
4. 将应用数据源绑定到对应环境的平台数据源。
5. 在数据集、逻辑流或其他能力中引用应用数据源名称，不直接复制平台连接参数。

成功标志：应用通过同一个应用数据源名称，在目标环境连接到管理员指定的平台数据源。

## 配置后端接口处理器

**后端接口** 页面管理平台已经发现的 Web API，不用于任意创建新路径。

1. 打开 **后端接口**，按 HTTP 方法和路径找到目标 API。
2. 核对范围：**内部**、**开放** 或 **公开**。
3. 选择处理器：逻辑流、`RequestMapping` 或 `RouterFunction`。
4. 使用逻辑流处理器时选择逻辑流；使用 `RequestMapping` 时核对类名和方法名。
5. 保存后使用匹配范围的调用方发起请求，核对状态码和响应体。
6. 需要撤销切换时点击 **复原**，再重复调用验证。

成功标志：目标方法和路径由选定处理器响应；复原后恢复发现时的处理方式。

## 调用外部接口

### 先配置身份认证

按外部系统要求选择 Access Token、明文凭据、HTTP Basic 或 AK/SK HMAC。凭据必须通过受控配置维护，不要写入逻辑流或页面。

### 再配置接口

1. 新建外部接口，填写名称、标题、分组和描述。
2. 选择认证凭据，填写 HTTP 方法和 URL。
3. 配置 header、query、body 或 cookie 参数。
4. 动态值使用 `${变量}`；平台配置值使用 `#{配置项}`。
5. 在高级设置中配置超时和重试。
6. 启用接口，并在逻辑流中用已知输入调用一次。

成功标志：请求携带正确认证和参数，响应可被逻辑流读取；错误凭据、超时和非成功响应按业务规则处理。

## 创建计划任务

当前页面只配置 Quartz Cron 周期任务。一次性调度由程序 API 提供，不在本页面创建。

1. 创建承担实际处理的逻辑流，并使用样例输入验证。
2. 打开 **计划任务**，新建任务。
3. 填写名称、任务描述、Quartz Cron 表达式和逻辑流。
4. 在任务数据中填写合法 JSON。运行时会将其转换为 Map 传给逻辑流。
5. 编辑前取得锁；页面标题出现 `*` 表示存在未提交更改。
6. 提交更改并等待一个触发周期，核对逻辑流产生的业务结果。
7. 不保留本次修改时，点击 **放弃变更并解锁**。

成功标志：任务按 Cron 触发，逻辑流收到任务数据，业务结果包含本次触发的可核对记录。

## 配置消息队列

当前默认中间件适配为 RabbitMQ。

1. 确定本应用是生产者还是消费者，并准备 Topic 或 Exchange。
2. 打开 **消息队列**，新建绑定。
3. 填写名称、描述、绑定类型和绑定目标。
4. 消费者选择处理消息的逻辑流；按中间件约定填写路由键或分区键、分组和 Binder 名。
5. 只有默认字段无法表达中间件参数时才填写自定义属性。
6. 提交更改；不保留修改时使用 **放弃变更并解锁**。
7. 发送一条带唯一标识的测试消息，确认消费者逻辑流产生对应业务结果。

成功标志：生产者可投递消息；消费者有运行实例，且唯一测试消息只按设计处理一次。

## 排障顺序

| 现象 | 先检查 |
| --- | --- |
| 数据源连接失败 | 驱动类型、URL、账号权限、网络和环境绑定 |
| API 仍由旧处理器响应 | 方法和路径是否完全匹配、处理器是否保存、是否已复原 |
| 外部接口返回 401 或签名错误 | 认证方式、凭据、动态参数和系统时间 |
| 计划任务未执行 | Cron、编辑是否提交、运行实例日志和逻辑流错误 |
| 消息没有被消费 | RabbitMQ、绑定目标、分组、消费者实例和逻辑流错误 |

正式环境的巡检与端到端验证见 [任务、消息与实时链路维护](../operations/task-message-and-realtime-link-maintenance)。
