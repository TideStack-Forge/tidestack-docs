# 页面交付：标准页面、动态表单与 UI Schema

## 选择页面方案

| 场景 | 使用方式 |
| --- | --- |
| 客户、合同、订单等长期维护的核心业务对象 | 业务模型生成的标准页面 |
| 问卷、报名、临时登记等轻量采集 | 动态表单 |
| 调整已有页面的结构、组件或动作 | 自定义 UI Schema |
| 复杂画布、专用可视化或重交互页面 | 微前端 |

同一份核心数据只选择一个主模型。不要同时用业务模型和动态表单维护，也不要为了少量布局调整创建微前端。

## 用业务模型生成标准页面

适用于需要长期维护、关联查询、权限控制和业务操作的数据。

1. 创建业务模型并定义字段、关系和必填规则。
2. 在 **视图配置** 中启用索引页、新建表单、编辑表单和详情页。
3. 发布模型，验证新建、查询、详情和编辑。
4. 自动页面不能满足要求时，关闭对应自动视图，再使用页面设计器调整。

成功标志：四类标准页面均可访问，字段校验有效，保存后列表和详情显示一致。

字段和视图配置见 [开发业务模型](../guide/tutorial/business-model/develop-business-model/)。

## 创建动态表单

适用于字段少、关系简单，且不需要先建立完整业务域模型的采集任务。

### 前置条件

- 已确定表单名称、标题和字段清单。
- 已确定哪些字段必填、哪些字段需要作为过滤条件。
- 表单名称确定后再部署；已下线的表单不能改名。

### 操作步骤

1. 进入系统设置中的 **动态表单管理**，新建表单。
2. 填写名称和标题。名称不能包含 `.`。
3. 添加字段，填写英文且唯一的字段名、唯一的显示名和字段类型。
4. 按业务要求开启 **必填** 和 **作为过滤条件**，再填写该字段类型的附加参数。
5. 保存并点击 **部署**。
6. 按页面提示刷新浏览器，打开生成页面。
7. 新增一条样例数据，检查必填校验；再通过过滤条件查询该记录。
8. 需要批量处理时，使用 Excel 导入和导出验证字段映射。

成功标志：表单状态为 **已部署**；生成页面可以新增、编辑、删除、筛选和导入导出数据。

### 下线或归档

| 当前状态 | 可执行操作 | 使用时机 |
| --- | --- | --- |
| 未部署 | 编辑、部署、删除 | 仍在设计，尚未产生运行数据 |
| 已部署 | 打开、下线、归档 | 正在使用，或准备停止录入 |
| 已下线 | 编辑、重新部署 | 暂停使用后调整字段 |
| 已归档 | 打开查询 | 永久停止写入但保留历史查询 |

部署、下线或重新部署后按页面提示刷新浏览器。已部署字段不能删除；已归档表单不能新增、编辑或删除数据。

## 覆盖或新增 UI Schema

适用于不改后端数据模型，只调整结构化页面的场景。

### 前置条件

- 已取得目标页面的完整路径。
- 已确认页面使用的数据接口和组件均可用。
- 覆盖已有页面前，已保留原 Schema。

### 操作步骤

1. 打开 `/system-setting/custom-ui-schema`，进入 **管理自定义页面**。
2. 新增记录并填写页面路径。覆盖现有页面时，路径必须与原页面完全一致。
3. 点击 **拉取页面**，载入该路径当前可用的 Schema。
4. 使用可视化编辑或代码编辑调整组件、布局、数据接口和动作。
5. 保存并开启 **启用**。
6. 重新打开目标路径，验证加载、查询、提交和错误提示。

成功标志：记录的 `enabled` 为开启状态，目标路径使用新的 Schema，关闭该记录后能够恢复原页面解析结果。

自定义 Schema 的运行时优先级高于内置 Schema。新增路径不会自动出现在导航中，还必须通过 UI 模型或菜单提供入口。DSL 和组件说明见 [UI Schema](../concepts/ui-schema/) 与 [前端 API](../api/frontend/)。

## 常见问题

### 动态表单部署后看不到新页面

先刷新浏览器，再确认表单状态为 **已部署**。仍不可见时，检查部署操作是否报错以及当前账号是否有页面权限。

### 自定义 UI Schema 保存后没有生效

确认记录已启用、路径完全匹配且 Schema 可以正常解析。覆盖页面时不要使用相似路径代替原路径。

### 页面需要大量专用交互

当 Schema 组件无法表达交互，或页面必须独立构建和发布时，改用 [微前端](../fusion-development/frontend-extension-paths)。
