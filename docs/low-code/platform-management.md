# 平台管理

平台管理面向平台管理员，负责为所有低代码应用提供公共入口和共享资源。它不属于某个应用的设计过程，修改可能同时影响多个应用。

## 平台级菜单

| 顺序 | 菜单 | 管理对象 | 主要使用者 |
| --- | --- | --- | --- |
| 1 | [运行实例](./development-platform-menus/runtime-instance) | 调试实例的创建、启动、停止和状态检查 | 应用开发者、平台管理员 |
| 2 | [打开应用](./development-platform-menus/open-apps) | 应用的创建、导入、查找和进入 | 应用开发者 |
| 3 | [应用模版](./development-platform-menus/app-templates) | 可复用的应用起点 | 平台管理员、应用负责人 |
| 4 | [平台数据源](./development-platform-menus/platform-datasource) | 各环境的真实数据库连接 | 平台管理员 |
| 5 | [平台组件库](./development-platform-menus/platform-component-library) | 可供应用导入的前端组件库 | 平台管理员、组件开发者 |

## 与应用开发菜单的边界

- 平台数据源保存真实连接；应用工作区中的“数据源”只建立应用名称与平台连接的绑定。
- 平台组件库负责安装和卸载组件包；应用工作区中的“高级功能 / 平台组件库”只维护当前应用的导入关系。
- 应用模版用于复制一套起始资产；由模版创建的新应用拥有独立生命周期，不会跟随模版自动更新。
- 运行实例管理调试环境的生命周期；应用开发页顶部的调试工具栏提供当前应用的快捷控制。

执行平台级删除、替换或凭据变更前，先确认引用它的应用以及目标环境，避免把局部维护变成跨应用故障。
