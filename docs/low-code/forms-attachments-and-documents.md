# 表单、附件与文档能力

## 选择存储方式

| 需求 | 使用能力 |
| --- | --- |
| 合同、客户、设备等长期业务数据 | 业务模型 |
| 报名、问卷、临时登记 | 动态表单 |
| 依附于一条业务记录的票据、图片或附件 | 业务模型中的文件上传或附件字段 |
| 独立的制度库、资料库或共享目录 | 文档管理 |

附件随业务记录管理；文档库拥有独立目录、权限和生命周期。不要用文档库代替业务模型，也不要把独立资料塞进单据附件。

## 为业务记录配置附件

### 前置条件

- 已确定附件属于哪个业务模型和业务记录。
- 已确定允许上传的文件类型、大小、数量和删除规则。
- 正式环境已为上传目录配置持久化、容量监控和备份。

### 操作步骤

1. 在业务模型中增加文件上传或附件字段。
2. 配置必填、文件类型、大小或数量限制；界面未提供的限制由扩展能力或网关执行。
3. 发布模型，在新建和编辑页面分别上传文件。
4. 保存记录后重新打开详情，下载文件并核对内容。
5. 使用无权限账号访问同一记录，确认页面和文件地址均不可用。
6. 删除测试记录或附件，核对保留和清理行为是否符合业务规则。

成功标志：文件与正确的业务记录关联，上传、下载、权限和删除行为均符合约定。

## 创建文档库

适用于跨业务记录保存资料，并按目录分配查看、下载和维护权限的场景。

### 创建资料结构

1. 打开 `/document-management`，创建文档库。
2. 填写名称和显示名称。名称只能包含字母、数字和下划线。
3. 进入文档库并创建目录。
4. 上传一份样例文件，完成下载、重命名和删除验证。
5. 在文档库设置中核对所有者；需要移交管理责任时执行 **转移所有权**。

成功标志：文档库可打开，目录可创建，文件可以上传、下载、重命名和删除。

### 配置目录权限

1. 打开目标目录的权限设置。
2. 添加授权对象并只授予完成任务所需的权限。
3. 使用目标账号验证允许的操作，再验证至少一个未授权操作。
4. 权限变化时修改授权；不再需要时撤销授权。

目录权限包括：查看、下载、创建文件、创建目录、重命名或移动、删除文件、删除目录和管理。不要用 **管理** 权限代替具体操作权限。

成功标志：授权账号只能执行已授予的操作；撤销权限后重新进入目录即失效。

## 运维验收

- 上传目录和文档库存储目录位于持久化存储。
- 备份同时包含文件内容和数据库元数据，并完成过恢复验证。
- 容量阈值和临时文件清理策略已生效。
- 无权限用户不能通过页面或直接地址取得文件。

存储、备份和恢复要求见 [运行能力维护要点](../operations/runtime-capability-maintenance)。需要转码、查毒、对象存储或外部文档系统时，使用 [融合开发](../fusion-development/)。
