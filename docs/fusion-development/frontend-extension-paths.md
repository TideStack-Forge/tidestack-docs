# 前端开发

前端开发从目标页面和交互出发。可以在平台中配置页面，也可以让 AI 调整 UI Schema、实现控件或生成微前端工程；最终都要接入平台页面、接口和权限链路。

## 明确页面契约

开始实现前，提供现有 UI 模型或页面地址、接口及数据样例、需要改变的交互、账号权限和宿主版本。有设计稿时一并提供，并说明加载、空数据、失败和禁用状态。

让 AI 先检查模型视图、Schema 和已有组件能否承载交互，再确定改动的位置。模型生成的标准页面先调整模型或视图；需要自定义实现的部分按下表选择入口。

## 按交付对象选型

| 交付对象 | 使用方式 | 具体实现 |
| --- | --- | --- |
| 完整复杂页面、独立子应用或一组路由 | 微前端应用 | [微前端应用](../guide/advance/extend-frontend/micro-app/) |
| 顶栏、侧栏、导航等平台框架区域 | 布局组件 | [布局组件](../guide/advance/extend-frontend/layout-component/) |
| 低代码页面中的可复用控件 | 组件库 | [组件库](../guide/advance/extend-frontend/amis-component/) |
| 企业品牌登录页、多种认证入口组织 | 登录页微前端 | [自定义登录页与认证接入](./custom-login-page-and-auth-integration) |
| 工作台、看板和首页入口拼装 | Widget 与仪表盘 | [工作台与 Widget](./workbench-widgets-and-component-libraries) |
| 向多个应用分发前端能力并管理版本 | 平台组件库 | [组件库制作与安装](./plugin-extensions/frontend/platform-component-library) |

两种组件交付方式及安装差异统一见 [前端插件扩展](./plugin-extensions/frontend/)。平台组件库负责跨应用分发和版本治理，实际组件仍按其页面、布局或控件职责实现。Widget 负责局部内容，仪表盘负责布局；这些对象不需要都变成独立微前端工程。

## 开发与接入顺序

1. **列出页面改动。** 对照现有模型、Schema 和组件，明确保留的能力、需要新增的交互及测试应用；Schema 调整沿用原有页面入口。
2. **准备所需工程。** 需要微前端、布局或组件工程时，按 [应用改造](../guide/advance/extend-frontend/application-transformation) 导出生命周期，配置 `publicPath` 和构建工具；按需共享 React 运行时。
3. **完成页面实现。** AI 按选定入口修改 Schema 或实现组件，并复用宿主提供的应用信息、请求、导航等能力。登录页还需遵守认证与回调边界。
4. **构建并安装产物。** 工程产物按 [微前端包管理](../guide/advance/extend-frontend/) 上传，使平台配置路径与构建产物的资源路径一致。平台组件库走其 ZIP 清单和安装流程。
5. **配置引用。** 将模型或产物关联到页面、登录入口、布局或组件注册位置，再从真实业务入口访问。
6. **验证交付。** 检查挂载、资源加载、卸载和重新进入，以及目标账号的权限、错误展示和业务结果。

## 保持页面与实现的职责清楚

某个业务对象只有少量页面超出标准能力时，可用微前端覆盖相应页面，其余页面继续使用低代码。布局组件只负责外壳和导航，业务状态与流程留在页面或业务服务中。

给表单补一个控件时，使用组件库并让 Schema 页面引用；需要多应用共享、独立安装和版本治理时，再增加平台组件库分发。工作台需求先评估 Widget 和仪表盘，独立子系统再使用微前端。

登录页只替换 `/login` 的展示和发起登录逻辑，回调与绑定继续由基座处理，详细边界见 [自定义登录页与认证接入](./custom-login-page-and-auth-integration)。

## 接入验证

- 从平台菜单或业务页面进入，产物能挂载，静态资源路径正确。
- 离开页面再进入时，事件、订阅和实例能够按生命周期释放与重建。
- 组件能在目标 Schema 页面使用；跨应用组件在导入后可用。
- 登录状态、权限、语言切换和接口错误符合宿主约定。
- 更新前保留上一版产物和配置，按 [协同验收要求](./high-low-code-collaboration#验收) 验证回退。

编写 UI Schema 或自定义组件时，可查 [PrismUI 开发参考](../guide/advance/amis-reference/)。
