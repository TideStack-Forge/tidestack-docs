# 工作台与 Widget

工作台由仪表盘布局与 Widget 内容组成。需要新增渲染能力时，通过 [组件插件](./plugin-extensions/frontend/)实现。先确定内容、配置和复用范围，再组织对应资产。

## 确定交付对象

向 AI 提供目标用户、已有仪表盘或模板、数据接口、尺寸要求，以及哪些内容可由用户配置。自定义 Widget 渲染器需要提供属性、注册类型和数据接口。

| 对象 | 负责什么 | 主要交付内容 |
| --- | --- | --- |
| Widget | 一块可配置内容 | 栏目定义、生成器参数、配置与内容 |
| 仪表盘模板 | 初始布局和组合 | Widget 引用、位置、尺寸与默认模板设置 |
| 用户仪表盘 | 用户保存的个人布局 | 个人选用模板和布局配置 |

独立路由或完整子系统按 [微前端应用](../guide/advance/extend-frontend/micro-app/) 实现；局部内容先复用已有 Widget 生成器和 Schema 组件。

## 创建可配置 Widget

1. 在 **门户栏目管理** 新建栏目，填写名称、显示名、描述和分类。
2. 选择生成器，填写其参数。AI 生成参数或页面内容时，核对生成器实际支持的结构。
3. 设置头部显示、配置对话框、最小和最大尺寸、默认尺寸及样式。
4. 保存后，在测试仪表盘添加该 Widget，填写并保存一组配置。
5. 刷新后核对配置与内容，验证最小、默认和最大尺寸。

先用一组真实数据确认内容与配置关联，再补空数据、接口失败和无权限状态。缺少渲染能力时实现组件；确需新增 Widget 生成方式时，沿用 `WidgetDefinitionGenerator` 等已有扩展入口及注册机制。

## 配置模板并验证个人布局

1. 新建仪表盘模板并填写名称、描述；需要作为初始布局时设置为默认模板。
2. 在 Dashboard 编辑器中添加 Widget，调整位置与尺寸并保存。
3. 用测试账号进入用户仪表盘，检查初始布局。
4. 点击 **开始编辑**，选择模板、调整并保存个人布局。
5. 重新登录，核对个人布局仍保留，并确认没有改变模板和其他用户布局。

模板更新与已有个人布局的关系应在测试账号上验证，不能只检查模板编辑器中的效果。

## 验证与交付

| 交付内容 | 必须观察的结果 |
| --- | --- |
| Widget | 可选、可配置，尺寸变化和刷新后内容正确 |
| 模板 | 初始组合正确，用户可保存自己的布局 |
| 恢复或移除 | 引用迁移、包和配置处理方式可执行 |

将定义、最小 Schema、配置样例、构建版本及实际验证交付。AI 排查时提供发生问题的层次：栏目生成、模板引用、组件渲染或页面调用，避免重复生成整套工作台。
