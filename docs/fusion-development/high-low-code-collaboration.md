# 高低开协同模式

本页定义业务开发人员与专业开发人员的交付边界。

## 默认责任

| 资产 | 业务开发人员 | 专业开发人员 |
| --- | --- | --- |
| 业务模型、标准页面和流程 | 负责 | 提供技术支持 |
| 菜单、角色、数据范围和通知 | 负责 | 审查安全边界 |
| 微前端、组件和布局 | 提需求并验收 | 负责实现和测试 |
| 字段、表达式、脚本和节点扩展 | 配置并验收 | 负责实现和注册 |
| 外部 SDK 与专用协议 | 提供业务契约 | 负责适配、监控和回滚 |

## 交接内容

业务开发人员提交：

- 无法由内建能力完成的最小场景。
- 输入、输出、权限和失败行为。
- 目标应用与验收数据。

专业开发人员交付：

- 对应的正式扩展点和安装包。
- 兼容平台版本、配置项和依赖。
- 单元测试、集成验证和故障日志。
- 安装、升级、卸载与回滚步骤。
- 业务人员可配置的使用入口。

## 验收

1. 在目标应用安装扩展。
2. 由业务开发人员通过平台配置引用扩展。
3. 使用有权限和无权限账号分别验证。
4. 模拟扩展失败，确认错误可定位且不会绕过权限。
5. 执行卸载或回滚，确认原有模型与数据仍可恢复。

没有明确扩展点、兼容版本或回滚方式的交付物不能进入共享环境。
